webcave · browser-based cluster rendering for CAVEs and display walls

Simulator — no server needed

  • CAVE, 4 screens, shapes
  • Tiled wall, 3×1, shapes
  • CAVE, glTF model (Damaged Helmet)
  • CAVE, glTF model, scene in the overview
  • CAVE, OpenVDB smoke volume (29 MB, decoded in the browser)
  • CAVE, OpenVDB particle point cloud (157 MB, 9.5 M points)
  • Wall 3×1, MapLibre map with 3D buildings (drag a tile to move all)
  • Wall 2×2, map (config default)
  • Wall 3×1, 2D population density choropleth

Applications: app=shapes, app=gltf with model=URL, size, spin, mx my mz, app=vdb with vdb=URL, density, steps, app=points with points=URL, maxPoints, or app=map / app=density with style, center=lng,lat, zoom, pitch, bearing (density: data, opacity). Press H in the simulator for all keys.

Cluster mode

Start the manager with npm run manager, then open one node page per display:

  • node front
  • node left
  • node right
  • node floor
  • simulator as controller of the running manager
  • node launcher: one computer, several displays (start the manager with --config cave-3m-1pc)

Node parameters: node, manager=ws://host:8765, stereo=anaglyph (override). Click a node to go fullscreen, press h to hide the HUD.
