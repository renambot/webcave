# WebGL Aquarium

The WebGL Aquarium from WebGLSamples (<https://webglsamples.org/aquarium/aquarium.html>),
Copyright 2009 Google Inc., BSD 3-clause license (LICENSE.md). This folder
holds its models and textures (`assets/`), the beam and bubble textures
(`static/`), the tdl helper library it is written with (`tdl/`), its shaders
extracted from the page into `shaders.json`, and `aquarium-core.js`, the
program adapted for WebCAVE (see that file's header for the changes). The
WebCAVE side is `src/apps/aquarium/`.
