Keyboard and mouse

Navigation — moves the whole CAVE through the virtual world

← →Turn left / right (yaw)
↑ ↓Look up / down (pitch)
I KFly forward / back, along the current heading
J LStrafe left / right
U ODown / up
RReset navigation to the origin and the head to its default position and orientation
SpacePause / resume the application's rotation (model, volume, points, map auto-rotate), for every screen
Enter / BackspaceApplication buttons primary / secondary (gamepad A / B). Shapes: A toggles auto-rotate

Gamepad — any pad the browser sees; standard layout, profiles for others

Left stickMove: strafe and forward / back (map: pan)
Right stickLook: yaw and pitch (map: rotate and pitch)
Triggers RT / LTUp / down (map: zoom in / out)
Y / TrianglePause / resume rotation
Back / SelectReset navigation and head
A B X, bumpers, d-padPassed to the application as primary, secondary, tertiary, prev, next, dpad. Shapes: A toggles auto-rotate

Connected pads and their profile show in the footer. Force a profile with ?gamepad=standard|xbox-linux|playstation-legacy.

Mouse on a tile — 3D apps; moves the navigation like the keys

DragLook: yaw and pitch
Right drag (or middle)Pan: strafe and up / down
WheelFly forward / back
Double-clickReset navigation and head

Head — the tracked viewer inside the CAVE, only with auto head off

W SMove forward / back
A DMove left / right
Q EMove down / up
Shift or Alt + W SPitch head up / down
Shift or Alt + A DYaw head left / right
Shift or Alt + Q ERoll head left / right

Head position sets each screen's off-axis frustum. Head rotation turns the cone in the overview and swings the stereo eye pair; it does not rotate the walls' images.

Map application — flat apps take the mouse in each tile

DragPan
Wheel · double-clickZoom
Right drag or Ctrl + dragRotate and pitch

The camera is sent to the manager and comes back to every tile and node, so all screens follow. The map is still until someone moves it (or autoRotate is set).
