● connecting

Cluster

Both switch every page connected to the Manager, without a restart. Switching resets the application state and the navigation; a configuration brings its own application, and nodes that are not in it wait until one that includes them returns.

Open

simulator control panel headset viewer

The simulator opens as a controller of this Manager: it mirrors the screens of the current configuration and drives head, navigation and stereo. The control panel is the current application's sidebar alone, for a tablet. Open the headset viewer on the headset.

Display nodes

One window per screen. open opens it on this computer; on a cluster, open each node's link on the computer that drives that screen (copy link), or launch it fullscreen and unattended below. A green dot means the window is connected and rendering.

Fullscreen on this computer's displays

For a node with several displays: pick which display shows which of its screens, then launch.

Windows open fullscreen on their display when the browser grants the window-management permission (Chrome, Edge, on https or localhost). Otherwise each opens on its display and goes fullscreen on the first click inside it.

A node with several screens needs several pop-ups, and Chrome opens only one per click: set Pop-ups and redirects to Allow for this site (icon at the right of the address bar) to get them all in one launch, or click open next window once per remaining screen.
